# Security Policy

## Supported version

Only the latest public FitDesi AI preview is currently supported for security fixes. Older preview APKs and historical branches may not receive updates.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in public GitHub issues, pull requests, screenshots, or social posts.

Use GitHub's private vulnerability reporting feature from this repository's **Security** tab when it is available. Include a concise description, affected area, safe reproduction steps, impact, and any proposed mitigation.

If private vulnerability reporting is unavailable, do not open a public issue with exploit details. Use the repository owner's private GitHub contact route and ask for a secure reporting channel.

## Sensitive information

Do not include any of the following in a report:

- API keys, tokens, passwords, keystores, certificates, or signing material
- Personal fitness, nutrition, health, profile, or device-identifying data
- Real user logs, screenshots with private information, or copied production secrets

Use redacted, synthetic, or minimal reproduction data instead.

## Scope notes

The current public preview is offline-first. Remote provider integrations are disabled by default. Security reports involving local persistence, generated fitness/nutrition guidance, build artifacts, credentials, or future provider boundaries are still welcome when reported privately.
