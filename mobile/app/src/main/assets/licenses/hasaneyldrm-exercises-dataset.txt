FitDesi imports specifically approved non-media exercise record data and
instruction text fields in English, Italian, and Turkish. The legacy exercise
asset retains 522 records and stable IDs but contains no image, GIF, video,
thumbnail, media-ID, or media-path fields. No upstream exercise media binary or
media-derived file is tracked or redistributed by FitDesi. The active 534-record
FitDesi knowledge pack also excludes media fields entirely.

This source-preparation notice corrects the earlier media-path description. The
previously signed Shipaton APK was not rebuilt and contains the earlier notice
wording; this correction changes only the proposed public source notice.
