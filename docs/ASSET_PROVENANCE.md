# Asset provenance

Status: **CURRENT for the public repository visual assets**, reviewed 2026-10-01.

## FitDesi logo

The project owner reports that the FitDesi logo artwork was generated with
ChatGPT. This record does not independently establish authorship, exclusivity,
trademark clearance, or the terms applicable to the generation. The existing
logo, launcher, adaptive/themed icon, splash, and in-app logo resources are
retained unchanged in this public source repository.

## Fitness banner

The previously tracked fitness banner had unresolved redistribution evidence
and no Android source or resource reference. It was removed from the accepted
sanitized source at commit
`ced40a37bab5b980765a4ff03a42960f7d318038`. It is not included in this public
source repository. This is an exclusion decision, not an ownership finding.

## Exercise media

Historical private audit evidence identified 521 image paths and 521 GIF paths
in the 522-record legacy exercise asset. The accepted sanitized legacy asset
retains the same 522 records and stable IDs but removes all image, GIF, media,
and media-ID properties and paths. No upstream exercise media binary is
included in this public source repository.

The active canonical knowledge pack remains unchanged at 534 exercise records.
Its reviewed non-media metadata and text are covered by the source and notice
boundary described in `docs/DATA_SOURCES.md` and
`THIRD_PARTY_NOTICES.md`.

FitDesi does not assert ownership of, or redistribution rights for, the
historical third-party exercise media.
